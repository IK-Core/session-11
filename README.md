# RECODE Session 11 · AI Project Lab

A 90-minute personal project studio. Students bring their own ideas and choose their own practical outputs. There is no project menu and no automated creative-quality score.

[Open Session 11 online](https://ik-core.github.io/session-11/), or open `index.html` in a modern browser. The HTML file is self-contained and can be shared by itself. No installation or AI API key is required. The app is not connected to ChatGPT: students write their own prompts, copy them, and work in their own ChatGPT chat.

Suggested pacing: IDEA 10 minutes, PLAN 10, RESEARCH 10, BUILD 30, TEST 10, IMPROVE 10, PRESENT 10. All stages are available for revisiting. Checkmarks are student-reported readiness, not grades.

Progress saves in the same browser on the same device when local storage is available. Use one working tab. Export the full JSON project regularly to preserve work and move between devices or future sessions. Importing replaces the current checkpoint after confirmation. The session guide includes a confirmed reset action.

Students can write text/code artifacts, preview HTML prototypes in a sandbox, download artifacts, attach up to 1 MB of files in total, or record a link to larger work. Full exports include the notebook, prompt drafts and versions, artifacts, attachments, readiness flags, and instructor review. A Markdown summary and printable showcase are available separately. Work kept in another tool must be shared separately or linked with suitable access.

The instructor desk is local and has no authentication. Instructors import the student JSON, inspect evidence, enter all six scores and a name, finalize the review, and export it with feedback. Project evidence changes mark a finalized review as needing an update. See `instructor_guide.md`.

The application records what students report. It never invents completed work or verifies that an artifact fulfills the objective.


Each browser keeps its own project. To move progress from a previous website, export the JSON there and import it here. Changing the website address does not transfer browser storage automatically.
